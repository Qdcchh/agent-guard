# 威胁模型与安全边界

状态：待实现并验证的安全目标，不是安全证明。

## 攻击者能力

攻击者可控制商品描述、报价附件等外部自然语言内容和代理输出；可取得普通授权凭证；可修改、复制、重放和并发发送请求；可掌握一个受限代理的会话私钥。不得因为凭证有签名就假定其持有者无恶意。

## 基础假设

- 授权根、可信身份/公钥绑定、执行网关及其服务密钥、可信状态库未失陷。
- 模拟下游执行幂等契约，网关与下游通信经过服务认证；数据库提供事务及持久性。
- 用于审计的独立密钥和可信检查点未被攻击者共同控制。
- 时钟在声明偏差内，密码库正确实现标准算法，部署密钥有适当隔离。

## 安全目标

1. 不接受超出结构化授权的工具执行，委托不扩权。
2. 被盗受限代理密钥不能突破自身授权范围；但不能保证其不恶意消耗已获授权。
3. 并发与重试不突破任何适用祖先额度；同业务键不重复效果。
4. 撤销提交后的新接受被拒绝，已接受操作遵循明确恢复语义。
5. 授权、请求、效果与审计证据可以关联检查，已锚定篡改及回滚可相对可信锚点检测。

## 非目标和局限

- 不保证模型不会被提示注入；重点是阻止越权副作用，而不是模型输出无害。
- 不抵抗授权根、网关、状态库和宿主机管理员等可信组件失陷。
- 不证明采购价格合理、现实交付真实或用户授权决策正确。
- 不承诺通用服务可用性、永久故障下的及时恢复、未知状态立即释放预算。
- 不将所有旧日志签名有效等同于当前日志完整。检查点后的未锚定尾部可能丢失，验证方缺少最新可信锚点时不能保证检测回滚。
- 普通 hash 可能泄露低熵数据信息，摘要不是加密；日志必须最小化，真实敏感载荷不以摘要替代访问控制。
- 单机分容器不等同于跨独立组织信任隔离，实验须如实描述部署强度。

## 安全实施要求

验权和状态库错误时失败关闭；密钥不进仓库和日志；请求及证据大小有界；nonce 状态清理不破坏有效窗口内的抗重放；恢复通道不能作为新操作入口；服务网络隔离与身份校验都要测试。具体密钥生命周期和管理认证在实现前冻结。
