为什么不需要大模型，也能验证安全边界

代理提出请求，网关决定能否执行。

本页用确定性代理复现同一套请求路径，真实执行密码校验、授权收窄、预算事务与证据验证。它验证的是可信执行边界，不是模型理解能力。

接入真实 LLM 后，安全责任如何划分？

模型或确定性代理负责提出工具请求；可信网关核验身份、参数、当前授权与共享预算，决定请求能否产生业务效果。即使模型受恶意内容影响，工具请求也必须经过这道边界。

这不保证模型不会被提示注入。本页的安全负例是构造请求与证据验证，不是实际 LLM 提示注入实验；真实 LLM 尚未接入。
