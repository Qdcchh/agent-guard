# 演示前端说明（给接手的开发代理）

## 范围
- 只改本目录的 `index.html`、`style.css`、`app.js`。服务器 `tools/teacher_demo_server.py` 只按白名单提供这三个文件，新增文件不会被加载。
- 页面内容集中在 `app.js` 的 `SCENES`（各页与时序图）、`CHAPTERS`（章节与章内分组）、`MODULES`（角色说明卡）、`FIXED_DEMOS`（现场运行结果）。事件契约见 `docs/teacher-demo-events-v1.md`。

## 页面结构
顶栏五章按汇报顺序递进，不再用场景编号：
1. 总览：系统图 + "要防住的四种风险"，每种风险链到对应页。
2. 权限检查：主要检查（令牌防盗用（持有者证明）、委托降权、撤销实时生效）+ 其他检查（参数篡改、共享预算、重放幂等、故障恢复）。
3. 协同签名：SM2 协同签名 + 对照页"为什么换掉旧版 FROST"。
4. 支付扩展。
5. 测试记录：分节顺序与顶栏一致，左栏目录显示各节实际状态。

每页左栏同一模板：章内导航 → 标题与问题 → 用到的协议 → 与原有做法相比 → 局限与边界 → 测试记录。右上角三种来源并列，当前来源点亮。
快捷键：数字 1–5 切章，`[` `]` 章内翻页，→ / ← 走步骤，Esc 关闭说明卡。旧链接 `#s1`…`#x402`、`#more` 仍可用。

## 运行
1. 打开 Docker Desktop。
2. `python3 tools/teacher_demo_server.py`，打开 `http://127.0.0.1:8765/`。也可以用桌面"CoSeal 演示服务器"启动，地址是 `127.0.0.1:18765`。
3. 本机页面可以点"现场运行"，公网页面只读。

## 硬约束（不可违反）
- CSP 为 `default-src 'self'`：不写内联脚本或样式，不用 CDN 和外部字体。
- 三种来源必须醒目区分：现场运行、记录回放、动画示意。不能用计时器或硬编码伪造成功。
- 红叉只能挂在真实拒绝的节点上，旁边写实际的拒绝码。
- 不展示完整令牌、私钥、签名份额、口令或数据库连接串。
- 局限照实写，例如"半诚实、n=2、同主机"，不能删。

## 视觉方向
- 浅色、简洁、几乎不用框，无框时序图（生命线）是页面主角。
- 页面上要写清用了什么协议、相对原协议改进了什么。
- 不允许任何文字或图形重叠，1366×768 投屏下也要清晰。

## 改完必须验证
```sh
node --check web/teacher-demo/app.js
node tests/test_teacher_demo_frontend_logic.cjs
python -m pytest tests/test_teacher_demo_server.py tests/test_cosm2_live_ui.py -q
```
最后在真实浏览器里按 1366×768 逐页截图检查，并在"协同签名""x402 支付"页各点一次"现场运行"。
