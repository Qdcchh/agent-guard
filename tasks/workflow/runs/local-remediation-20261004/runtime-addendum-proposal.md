1. 当前主会话继续担任主控；不声称工具未证实的有效模型/档位。实施子任务创建时显式请求 `gpt-6.1-sol / medium`，包审和每轮独立验收显式请求 `gpt-6-astra / high`。保留实际工具调用参数、返回任务路径、完成状态及证据来源；未暴露的有效元数据记 UNKNOWN，不要求移植整个 OpenCode/Codex 控制系统才能开始本次产品补正。
2. 每轮新 reviewer；包审与实现验收分离。单 worker 串行修改共享结果/参数/测试边界，停写后完整冻结；无同文件并行。主控不代替 reviewer 给行为 PASS。
3. 使用本轮版本化状态与检查清单，验证真实用户授权、精确文件所有权、包审结论、起止内容哈希、writer/测试进程停止、资源归属、原始命令退出码/JUnit和逐项矩阵。保留原门，只记录它的历史语义，不修改它以伪造兼容。此替代为本轮人工与工具证据核验，不宣传为通用自动机器门迁移。
