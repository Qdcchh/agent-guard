# Codex 工作流补充契约 v1

这是新的运行入口，原文件一字不改。仅取代旧入口中的工具启动方式、角色模型和运行身份绑定方式；不降低原始需求、授权、独立性、证据与验收标准。旧 OpenCode/MiMo/Flash 名称和初始状态属于历史。更高优先级的安全限制始终有效。

## 三个角色

- 主会话：gpt-6-astra / medium；主控独占授权核对、计划、state、issues、调度台账和最终阶段记录。
- ag_sol_worker_v1：gpt-6.1-sol / medium；实施、串行共享前置包、串行整合、获批范围内补正。
- ag_astra_reviewer_v1：gpt-6-astra / high；每轮创建新独立子会话，包审与实施验收严格分开。

## 必须保留的工作顺序

1. 读取真实用户授权、HANDOFF、当前状态、完整原始需求、全部历史问题和原 workflow 契约/模板。不能从旧 README 的初始 A2.1 状态重新开工，也不能凭配置授权推定实施授权。资料不足先列缺口。
2. 主控冻结版本化任务包：全阶段需求 ID、行为、调用方、允许的精确文件、只读依赖 SHA、测试矩阵、资源隔离、停止条件及真实授权来源。新 reviewer 做 PACKAGE_REVIEW；PACKAGE_READY 只表示包准备好，不是行为 PASS，也不是实施授权。
3. 共享接口、迁移、依赖、锁序和 fixtures 由一个 worker 串行完成并停写冻结；其后默认两个、最多三个无文件冲突的 worker。每包列精确路径，禁止目录/glob 或同文件分函数并发。各包有独立资源/证据/缓存目录，不消费同批半成品。不足以并行则明确串行。
4. 派发前同时满足真实用户授权、包审、受支持的 Codex 运行绑定与原门的语义要求。配置或 JSON 声明不证明这些条件。当前本包 runtime-bindings.template.json 故意留空，dispatch_ready=false，不具有放行能力。
5. 记录实际父子 thread/task 身份、角色、有效模型/档位的证据来源、状态、文件与资源 owner。创建成功只记 RUNNING；通知/回执缺失记 UNKNOWN，平台拒绝记 BLOCKED，中断记 INTERRUPTED。不能改原生数据库、伪造回执、用聊天声称代替运行元数据。
6. worker 自查交付完整报告、真实命令/退出码/log/JUnit、差异与输出哈希后停止；所有 writer 及其写进程已真实停止，核对精确写范围、只读依赖、资源和全候选后才冻结。冲突为 NEEDS_REPLAN，停写、重新分包和审包。
7. 单一 worker 串行整合共享调用方和全阶段报告。冻结完整候选后由新的 reviewer 做 IMPLEMENTATION_ACCEPTANCE：覆盖当前完整要求、历史失败、跨包契约、前段回归，亲自运行必需测试。真实 PostgreSQL、进程/并发/故障与负控按原合同执行；测试替身、历史日志、局部通过数不能代替。
8. 缺陷按稳定 ID 补正，仅在已批准阶段/范围内持续；每轮新快照、新独立 reviewer，保留失败轮。实现者只能标 FIXED_PENDING_REVIEW，不能自己关闭问题。主控读回完整矩阵与原始证据，无阻断且全部正式门有效通过后才接受。缺失测试/资料/运行绑定时保持 NOT_ACCEPTED/BLOCKED。
9. 每个大阶段结束停给用户查看并等明确批准；不自动进入 A2.2/A2.3/A3、Git 发布、部署或新修复。GitHub 交付是独立的范围授权，不能据此批准实施。
10. 恢复前核对原 writer/进程和精确资源 owner；未知就停，禁止重复写入和广域清理。遇平台、安全或权限阻断，报告并停止受阻动作，不能换模型、会话、环境、接口或工具绕过。

## 旧机器门与新运行适配边界

原 tools/workflow_gate.py、OpenCode parallel_gate.py、cloud_gate_v3.py 及历史 DB/schema 保留原样。不能把 Codex thread ID 冒充旧 session/task ID，不能为了通过门改旧 state 授权、旧模型或哈希。

新 runtime-bindings.template.json 是待采集字段清单，不是 Codex 官方配置，也不是验证器。check_config.py 仅静态检查本包，绝不能用它替代 plan/worker/freeze/accept 门。当前尚无通过真实 Codex 回执验证的完整机器门移植，不得声称已实现端到端自动验收。

未来若用户批准安全范围的正式迁移，需另外实现并独立验证版本化适配器：核验受支持原生身份/父子关系/有效模型档位、实际停止、授权原文、任务包/快照/范围/资源、独立测试证据和完整矩阵；新旧契约哈希均保留。先用合成数据覆盖错误模型、失联 writer、版本漂移、缺授权、旧审查复用等拒绝路径，再按许可做无业务副作用预检。平台阻断必须另经支持的授权渠道解除。以上都是解除条件，非当前执行指令。
