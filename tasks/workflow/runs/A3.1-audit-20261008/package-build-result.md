# A3.1 正式业务建包读回与接口决策

两建包worker均原生STOP，业务资源0；其ignored readback保留原件。主控完整读回接口合同与继承计划，stdlib解析17.5MB继承绑定。remote-ahead仅checkpoint链不能证明所有中间记录，正式v1包含只读reader /v1/audit/records、RecordPage与client.records；沿既有S1精确allowlist，不增owner路径，由本轮独立业务包审核安全/验收可行性。未改变A3.1原95原子、原119/112/269或后段边界。

主控在worker停写后消解合同recorded_at的秒/文本措辞：实际为UTC微秒精确文本，对应非负Unix时刻；同步合同SHA。原worker输出SHA及readback历史保留不冒称改后原件。尚未实施新函数不当包审阻碍，真实collect/运行绑定是实施STOP后门。

任务包保持PACKAGE_REVIEW_PENDING，授权true、dispatch_ready=false；新reviewer请求gpt-6.1-sol/high，有效metadata UNKNOWN。包审期间主控和所有writer冻结受审候选；不创建业务资源、不修改Git。
