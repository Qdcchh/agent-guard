# S0 public interface freeze proposal

This is a proposal for controller review, not a self-authorized package freeze. The nine implementation members and exact SHA256 are in final-code-members.json.

Receipt API: ReceiptComponents(token_jws: bytes, proof_jws: bytes, ancestor_tokens: tuple[bytes, ...], request_raw: bytes, result_raw: bytes, ledger_raw: bytes, receipt_jws: bytes, quote_raw: bytes | None = None, context_raw: bytes | None = None, source_raw: bytes | None = None); verify_receipt_components(components, trust) returns the existing VerifiedReceipt with UNANCHORED status. ReceiptTrust and ReceiptVerificationError are reexported by receipt.py. Existing v1 verification delegates to the same semantic verifier. Request bytes remain original; signed JWS and optional context/source/quote material are checked against authenticated claims. Errors use ReceiptVerificationError.

Task codec API: object_id(object_kind, owner_type, owner_id, component, ordinal=0); index_seed/fold and wire_seed/fold implement the frozen profiles; encode_object_chunks(kind, id, raw) yields canonical LF-terminated NDJSON bytes; iter_frames(binary_stream) yields validated frames. Exhaust the iterator to verify footer and EOF. This codec does not replace S1 full journal/reference/business verification. Constants enforce 24576-byte chunks, 65536-byte lines, 256 MiB wire, 400000 frames, 200000 objects, 100000 journal records and 20000 operations. TaskBundleError is the public failure class.

History API: load_checkpoint_history(binary_stream, *, external_trust, external_pin) returns frozen CheckpointHistoryDescriptor(sha256, wire_bytes, checkpoint_count, scope, last_checkpoint_id, last_sequence, last_jws_digest, source_path), with open_readonly() for identity/SHA-checked reopen. Supply a readonly regular local file handle, not BytesIO or writable handles. External trust has scope (JournalScope or exact five-field dictionary) and audit_keys tuple[CheckpointTrust, ...]; an object exposing those attributes is also accepted. External pin is the exact dictionary mode/checkpoint_jws/observed_at/scope. UNKNOWN requires null JWS/time; MINIMUM has genuine JWS and nullable observation; LATEST_OBSERVATION has genuine JWS and UTC integer observation. Signed history checks scope, role/range, original-JWS previous digest, ordering and terminal pin. UNKNOWN does not establish latestness: S1 exporter must independently compare its cached terminal or require empty history when there is no cache. Public malformed-history failures normalize to TaskBundleError.

Auth API: load_export_credentials(value) returns tuple[ExportCredential, ...]; authenticate_export(authorization, task_id, *, credentials) returns trusted (tenant_id, task_id). Credential rows contain credential_id, credential_sha256 (lowercase SHA256 hex), tenant_id, task_ids; header is AGExport credential_id:secret. Separate secret is URL-safe 32..256 characters. Invalid setup/auth uses ConfigError. load_evidence_local_inputs(value) requires exact trust_file/external_pin_file/external_checkpoint_history_file canonical absolute distinct existing regular nonsymlink paths. Gateway evidence_operator_inputs(value) returns (credentials, local_inputs). CLI optional export ID/tenant/tasks and all three local-file flags are all-or-none; no export route was added.

Public fixture entry points in tests.fixtures.a32_common: signed_receipt_material(noncanonical_request=False), checkpoint_material(sequences=(1,2,3), mode=..., scope=None), task_header, encode_task, receipt_objects, public_trust_input(material, checkpoint, *, registration, catalog), signed_task_material(mode=LATEST_OBSERVATION, noncanonical_request=True). Fixtures use fresh genuine SM2 signatures, complete receipt byte components, stable object IDs/refs and external public trust/pin/history ingredients. Public trust JSON is AG-TASK-TRUST-1; SPKI DER values are unpadded base64url, public keys only. Historical holder registrations include tenant/client/did/kid/spki_der/active/role; role is HOLDER. Audit entries have AUDIT_SIGNER role and sequence bounds. Registration uses the frozen seven fields; scope uses the frozen five fields. S1 workers may independently consume these public ingredients and adapt JSON SPKI into ReceiptTrust/CheckpointTrust. signed_task_material is synthetic codec/journal/signature fixture material, not a claim of native PG business execution or complete S1 verification acceptance.
