1. 主控请求 gpt-6.1-sol/high，worker 请求 gpt-6.1-sol/medium，每轮包审与实施验收使用全新独立 gpt-6.1-sol/xhigh reviewer。记录原生任务路径、实际请求和运行/完成回执；有效后台模型/档位未暴露就记 UNKNOWN，不补造身份或机器门通过。

4. worker 和每轮 fresh reviewer 分别使用独立 Python3.11、真实 PG16、独立网关/下游事务域、真实 SDK/SM2/SM3、受信 CA/hostname TLS、独立 source 与非 editable wheel。完整普通/PG 测试、依赖锁、迁移及 checksum、实际父子进程 import provenance、并发每组10轮、故障/负控按正式包实跑。只使用本轮 TEST DSN，不连接或清理无关容器与部署库，不输出可用凭据/原始 token/私钥。
